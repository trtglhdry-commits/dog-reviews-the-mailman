One funny one-line review a dog gives the mailman, for the make.fun bounty "The Dog Reviews the Mailman". The program writes a single deterministic line to `entry.txt` — a one-star review from a dog who has barked at the mailman 214 times and is still waiting on his treats.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/dog-out node main.ts
```

## Entry

> One star: he visits every day at 10, drops the bills in a box I can't open, and runs. I barked at him 214 times — he still owes me one treat per bark.
